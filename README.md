# Unsub

Unsub is a web-based game. I thought of this idea as a sequel to my previous "useless" genre of projects. 
The goal is to unsubscribe from a suspicious company's persistent newsletter! As always, they make it as complicated as possible! The game features several "stages" of verification. I won't spoil any more! Go play it! :D

Important note; the company in the game - "Fraude" is fictional and does not represent nor is affiliated with any real companies. The name is simply the French word for "fraud".
